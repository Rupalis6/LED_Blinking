# Arduino LED Blinking Project

## Description
This project demonstrates basic LED control using Arduino Uno.

## Components
- Arduino Uno
- LED
- 220 Ohm resistor
- Breadboard
- Jumper wires

## Working
The Arduino turns the LED ON for 1 second and OFF for 1 second continuously.

## Objective
To demonstrate basic GPIO control and apply GitHub-based QA documentation.
